# Workflows exportados

En esta carpeta deben guardarse los archivos exportados desde `n8n`.

## Convencion sugerida

- `workflows/helpdeskbot-main.json`
- `workflows/helpdeskbot-reportes.json`

## Recomendaciones

1. Exportar siempre la version mas reciente antes de entregar.
2. Verificar que el workflow no incluya credenciales sensibles.
3. Mantener nombres de archivo claros y consistentes.

## Siguiente paso

Cuando tengas listo el flujo real en `n8n`, exportalo y guardalo aqui para que el repositorio quede completo.
